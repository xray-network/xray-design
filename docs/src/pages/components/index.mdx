# Components

This catalog turns the design protocol into stable visual references for humans and coding agents.
Every specimen shows both supported themes and links to machine-readable metadata.

> The standalone `@xray-network/xray-ui` package has not been published yet. These are
> documentation-only protocol specimens. Once the package exists, this site should pin an exact
> package version and replace specimen markup with imports from the real library.

| Component | Contract |
| --- | --- |
| [Button](./button) | Actions, variants, focus, and disabled behavior |
| [Tag / Badge](./tag) | Environment, status, and delta labels |
| [Account Avatar](./account-avatar) | Geometric account identity |
| [Asset Row](./asset-row) | Asset identity, balance, and delta |
| [Balance Card](./balance-card) | Price-tag numeric presentation |
| [Payment Form](./payment-form) | Complete asset-transfer composition |

Agents can read the [component catalog](https://wiki.xraynetwork.io/design/components.json), its
[JSON Schema](https://wiki.xraynetwork.io/design/components.schema.json), and the combined
[reference manifest](https://wiki.xraynetwork.io/design/manifest.json).
