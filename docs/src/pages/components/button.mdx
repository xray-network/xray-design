# Button

Capsule action control with four semantic variants. Use one blue primary action per visual region.

<ReferenceStatus />
<ButtonShowcase />

## Target API

```tsx
import { Button } from "@xray-network/xray-ui"

<Button variant="primary">Continue</Button>
```

Required variants: `primary`, `gray`, `outline`, and `success`. Required states: default, hover,
pressed, focus-visible, and disabled.
